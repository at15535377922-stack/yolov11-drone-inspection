## 设计方案（论文 §6.5）

### 问题定位

EXP-03 表明，仅靠轻量加权跨尺度融合并不能继续提升低空巡检小目标检测性能。整体 mAP50 从 0.335 降到 0.332，bicycle 和 awning-tricycle 也未改善，说明“按尺度分配权重”虽然能够提供更稳定的融合骨架，但对复杂背景中的目标主体、边缘纹理和局部异常区域缺乏更细粒度的显著性增强。

VisDrone 场景具有背景复杂、尺度变化大、小目标密集和局部遮挡明显等特点。对于 `pedestrian`、`bicycle`、`awning-tricycle` 这类目标，仅做 P2 分支和加权融合还不够，网络还需要在融合后的关键特征上进一步突出目标相关通道与空间响应，抑制背景噪声。

### 改动内容

在 EXP-03 的 `P2 + LWFusion` 结构基础上，于四个 Detect 输入前分别加入一个轻量 `CBAM` 模块：

```text
P2_feat -> CBAM -> Detect
P3_out  -> CBAM -> Detect
P4_out  -> CBAM -> Detect
P5_out  -> CBAM -> Detect
```

`CBAM` 由通道注意力和空间注意力串联组成：

$$
F' = M_c(F) \otimes F
$$

$$
F'' = M_s(F') \otimes F'
$$

其中：

- $M_c(\cdot)$ 表示通道注意力，用全局池化后的通道响应重标定各通道重要性；
- $M_s(\cdot)$ 表示空间注意力，用空间显著图增强目标区域、抑制背景区域；
- $\otimes$ 表示逐元素乘法。

本次实验不改 Backbone，不改 Detect Head，不改 LWFusion 的融合方式，只在最终送入检测头前增加轻量显著性增强，验证“先加权融合，再注意力增强”是否能改善小目标和复杂背景场景表现。

### 接入节点

本次注意力增强覆盖 4 个检测尺度输出节点：

1. `P2_feat`（极小目标）
2. `P3_out`（小目标）
3. `P4_out`（中目标）
4. `P5_out`（大目标 / 全局结构）

## 预期结果

| 指标 | EXP-03 | EXP-04 预期方向 | 依据 |
|---|---|---|---|
| mAP50（整体） | 0.332 | **↑ +0.01~+0.03** | 注意力增强目标显著性 |
| mAP50-95（整体） | 0.191 | **↑ 小幅提升** | 边缘与局部区域响应更稳定 |
| Recall | 0.349 | **↑ 小幅提升** | 复杂背景下漏检减少 |
| bicycle AP50 | 0.0877 | **↑ 明显优于 EXP-03** | 小目标纹理与边缘增强 |
| awning-tricycle AP50 | 0.0927 | **↑ 明显优于 EXP-03** | 同上 |
| pedestrian AP50 | 0.386 | **↑ 中等提升** | 细粒度主体响应更集中 |
| 推理速度 | 1.2 ms* | 略慢 | 增加轻量注意力模块 |
| 训练稳定性 | 稳定 | 持平或略降 | 结构复杂度略增但 batch 不变 |

> 注：EXP-03 的 `1.2 ms/img` 为该次 `val` 输出的纯 inference 时间，仅作参考，后续横向比较需统一验证口径。

### 判定标准

- 若整体 mAP50 相比 EXP-03 提升 ≥ 0.01，且 bicycle / awning-tricycle 至少有一类改善明显，则认为轻量注意力增强有效。
- 若整体指标提升有限，但小目标类和 pedestrian 有稳定改善，仍可保留该模块进入后续联合实验。
- 若总体与小目标类均无改善，则说明当前 CBAM 接入位置或注意力形式不适合本任务，应转入损失函数方向继续优化。

## 主要观察

- 整体 mAP50 和 mAP50-95 与 EXP-03 完全持平（均为 0.332 / 0.191），说明 CBAM 在当前结构下没有带来额外整体增益。
- 小目标类没有显著改善。bicycle 从 0.0877 微降到 0.0875，基本持平；awning-tricycle 从 0.0927 小幅升至 0.0938（+0.0011），属于微幅波动范围内。
- bus 类有较大反弹（+0.030），可能与小样本量和训练随机性有关，不可直接归因于 CBAM 自身。
- Recall 略升（+0.007），但 Precision 略降（-0.005），属于接近持平的范围内波动。
- 参数量小幅增加（2.77M → 2.856M），FLOPs 社小增加（10.5G → 10.6G），师当初设计的“轻量”細符合。
- 总体结论：CBAM 在当前多层叠加实验框架（P2 + LWFusion）下，没有带来进一步的可量化收益。当前三个模块叠加（P2 + LWFusion + CBAM）并不能长足，后续应把设计重心转向小目标损失函数优化。

---

## 结论与后续规划

**结论**：

- EXP-04 未达到预期。CBAM 注意力在 P2 + LWFusion 坚地上并没有带来额外的可量化收益，整体 mAP50 / mAP50-95 与 EXP-03 完全持平。
- 结合 EXP-02、EXP-03、EXP-04 的走势可以判断：当前的结构改动（P2 + 加权融合 + 通道空间注意力）已基本将当前尜度和读头部分模块叠加的边际收益用尽。
- 后续不需要在当前结构上继续叠加更多注意力模块，应转入 EXP-05 小目标损失函数优化（IoU + NWD），对核心小目标类（bicycle、awning-tricycle）进行直接增强。
- CBAM 可在 EXP-07 全量模型阶段统一参与评估，不必单独保留为有效次级模块。
