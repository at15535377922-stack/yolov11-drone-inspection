## 设计方案（论文 §6.4）

### 问题定位

EXP-02 证明单独增加 P2 分支只能带来有限增益：整体 mAP50 从 0.320 提升到 0.335，但 bicycle 和 awning-tricycle 的提升很弱，同时带来了明显的计算与显存成本。一个直接原因是：EXP-02 在各尺度融合节点仍使用普通 `Concat`，默认不同尺度特征贡献相同，浅层噪声和深层语义被一并送入后续卷积，网络无法显式学习“当前任务更该依赖哪一层”。

### 改动内容

在 EXP-02 的 P2/P3/P4/P5 关键融合节点，将：

```text
Upsample/Downsample + Concat + C3k2
```

替换为：

```text
Upsample/Downsample + LWFusion + C3k2
```

其中 `LWFusion` 当前实际实现为：

$$
X'_i = \mathrm{Conv}_{1\times1}(X_i)
$$

$$
\hat{w}_i = \frac{\mathrm{ReLU}(w_i)}{\sum_j \mathrm{ReLU}(w_j) + \epsilon}
$$

$$
F_{out} = \sum_i \hat{w}_i X'_i
$$

模块特点：

- 每个输入分支先用独立 `1×1 Conv` 对齐到统一通道数，再做加权融合；
- 每个输入分支只额外引入一个可学习标量权重，参数增量仍然较小；
- 不改 Detect 头，不改 Backbone，不引入重型注意力；
- 重点验证“仅靠轻量加权融合”是否能释放 P2 分支潜力。

### 接入节点

本次替换覆盖 6 个双路融合节点：

1. `P5↑ + F4`
2. `P4↑ + F3`
3. `P3↑ + F2`
4. `P2↓ + P3`
5. `P3↓ + P4`
6. `P4↓ + F5`

## 预期结果

| 指标 | EXP-02 | EXP-03 预期方向 | 依据 |
|---|---|---|---|
| mAP50（整体） | 0.335 | **↑ +0.01~+0.03** | 自适应抑制无效尺度噪声 |
| mAP50-95（整体） | 0.194 | **↑ 小幅提升** | 融合质量更稳定 |
| Recall | 0.348 | **↑ 小幅提升** | 小目标匹配更聚焦 |
| bicycle AP50 | 0.0967 | **↑ 明显优于 EXP-02** | P2/P3 权重应更偏向小目标有效尺度 |
| awning-tricycle AP50 | 0.0956 | **↑ 明显优于 EXP-02** | 同上 |
| 推理速度 | 12.7 ms | 持平或略慢 | 仅新增轻量加权和 1×1 混合 |
| 训练稳定性 | 存在 assigner OOM 回退 | **优于 EXP-02** | batch 已降到 16，降低显存压力 |

### 判定标准

- 若整体 mAP50 相比 EXP-02 再提升 ≥ 0.01，且 bicycle / awning-tricycle 至少有一类提升明显，则认为 LWFusion 有效。
- 若整体指标持平但速度代价更低或训练更稳定，也可认为该设计有保留价值。
- 若小目标类仍无改善，则说明仅做加权融合不足，后续需依赖注意力或损失函数继续补强。

## 主要观察

- 小目标类没有较 EXP-02 进一步改善。bicycle 从 0.0967 降到 0.0877，awning-tricycle 从 0.0956 降到 0.0927，说明轻量加权融合单独使用并未释放 P2 分支优势。
- 整体指标轻微下降：mAP50 从 0.335 降到 0.332，mAP50-95 从 0.194 降到 0.191。Precision 和 Recall 基本持平，说明该模块更多是“重分配各尺度贡献”，没有产生新的稳定增益。
- 训练稳定性明显优于 EXP-02。`batch=16` 下实验完整跑通，未再暴露此前频繁的 `TaskAlignedAssigner` 显存回退问题，这说明当前结构更适合作为后续实验底座。
- 参数量和 FLOPs 略有增加（2.66M → 2.77M，10.2G → 10.5G），但增加幅度较小，符合“轻量融合”的设计目标。
- 本次 `val` 输出中的纯 inference 时间为 1.2 ms/img，明显低于 EXP-02 的 12.7 ms/img；这更多反映了两次验证批大小与运行路径差异，不能直接作为严格的推理加速结论。论文中应以同一验证设置下的速度数据做横向对比，避免误写为结构本身显著提速。
- 结论上，LWFusion 作为单独改进模块不成立，但它提供了一个更稳定、代价较低的融合骨架，适合继续叠加 EXP-04 的轻量注意力增强模块。

---

## 结论与后续规划

**结论**：

- EXP-03 没有达到预期。轻量加权跨尺度融合未能在 EXP-02 基础上继续提升总体精度，且对 bicycle、awning-tricycle 等核心小目标类别存在轻微退化。
- 该结果说明：仅靠“标量权重 + 线性融合”不足以显著改善低空巡检小目标的细粒度辨别能力，后续需要引入更具选择性的空间/通道增强机制。
- 不过，EXP-03 的训练过程更稳定，且模块额外代价较小，因此可将其视为一个可继续叠加的融合底座，而不是最终可单独保留的改进模块。
- 下一步应进入 EXP-04，在当前 `yolo11-p2-lwf` 结构基础上，于关键融合节点后加入轻量通道-空间注意力，验证“先加权融合、再局部增强”是否能真正改善极小目标 AP。
